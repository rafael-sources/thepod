FEATURES

Every tool in detail

A detailed guide to amaPod's moderation and broadcast tools.

01 Event management

The main screen lists your events with their state (Created, Active, Ended). For each event:

  • Create: title, description and chat mode. Optionally from a template.
  • Edit: adjust the details as long as the event hasn't ended.
  • Activate: opens the video room and enables the real-time queue.
  • End: closes the room and triggers the export to postPod if there was a recording.
  • Delete: only available in the Created state — an active or ended event keeps its history.

02 Templates

Save an event's settings as a template (title, description, chat mode, branding) and create recurring events in one click. Ideal for weekly formats.

03 Moderation queue

The central panel during an active event. It's divided into:

  • Pending: new requests with name and pre-questions. Buttons to approve or reject.
  • In queue: approved participants, ordered by position. You can reorder them at any time — positions renumber themselves.
  • On air: whoever is asking their question right now. When you move to the next one, the current one is marked as handled.

Each card shows the participant's pre-questions so the host knows what's coming.

04 Pre-questions

When signing up, each participant can write up to 3 questions and edit them while they wait. The moderator sees them in the queue — they're useful for filtering, ordering by interest and preparing the host.

05 Automatic pre-connection

The first 3 in the queue get the pre-connection signal: their browser connects to the room (camera and microphone ready) without going on air yet. When the moderator advances the queue, the pre-connection flags are recalculated automatically.

06 Censor a participant

Cuts the audio and video of the participant on air immediately. The event goes on — only that person is neutralized. They're marked as censored in the history.

07 Chat

Configurable per event:

  • Open: messages visible instantly to everyone.
  • Moderated: messages from the audience go into an approval inbox; the host decides which ones get posted. The host's messages are posted directly.
  • Off: no chat.

08 Viewers' page

Each event has a public viewing page. The audience follows the broadcast without an account, sees the question queue and can give likes — the counter is shown live. From there they can also ask to participate, moving into the pending queue.

09 Recording

Recording controls from the event panel:

  • Start / stop: records the composite room as an MP4 file on the server.
  • Status: indicator for a recording in progress.
  • Download: get the MP4 once the recording has finished.

Unlike prodPod (which records separate tracks per participant), amaPod records the event's composite view — meant for archiving and clips, not for multitrack editing.

10 Export to postPod

When an event with a recording ends, amaPod creates (or updates) a project in postPod with the event's MP4, ready to cut out the best moments and publish them as clips.
