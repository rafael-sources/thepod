¿CÓMO SE CONECTAN?

El flujo natural

PREPOD
Planeas

Episodio + guion + invitados + calendario.

→
PRODPOD
Grabas

Sesión en vivo, video multipista, marcadores.

→
POSTPOD
Editas

Cortes, captions, mejoras, export listo para subir.

Cada app pasa el contexto a la siguiente automáticamente: prePod le dice a prodPod quién participa y cuándo, prodPod le entrega a postPod los archivos grabados con marcadores. Una sola sesión, tres herramientas, cero copy-paste.
